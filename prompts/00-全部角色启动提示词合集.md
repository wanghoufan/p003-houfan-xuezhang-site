# 全部角色启动提示词合集

> 本项目多 Agent 协作的启动提示词集合。日常使用：发送「中括号关键词 + 角色 + 当前任务」，Agent 自行读取 `AGENTS.md` 与对应角色规范。
> 规范来源：`AI编程项目模板-v2.2`（交接上下文 V1.0，2026-08-17）。

## 角色关键词速查
- `【计划】` → `prompts/01-【计划】技术规划师.md` + `docs/roles/planner.md`
- `【开发】` → `prompts/02-【开发】开发实现工程师.md` + `docs/roles/builder.md`
- `【审查】` → `prompts/03-【审查】代码审查工程师.md` + `docs/roles/code-reviewer.md`
- `【测试】` → `prompts/04-【测试】质量测试工程师.md` + `docs/roles/qa.md`
- `【产品】` → `prompts/05-【产品】产品体验审查员.md` + `docs/roles/product-reviewer.md`
- `【修复】` → `prompts/06-【修复】开发实现工程师.md` + `docs/roles/builder.md`
- `【收尾】` → `prompts/07-【收尾】neat-freak.md`

## 通用前置（每个角色启动都带）
1. 先读 `AGENTS.md`（项目总入口、公共规则、文档路由）。
2. 只读取当前任务真正需要的角色规范与项目文档，避免无关上下文膨胀。
3. 源真值：`app/content.ts`（内容）、`app/ContactPanel.tsx`（联系方式）、`public/photos/*.webp`（照片）。
4. 不臆造项目 / 资质 / 联系方式 / 照片；不删除或移动个人源照片；不自动 commit/push。
5. 发布前必须通过 `npm test`；一次 push 到 `main` 同时更新 Vercel 与 GitHub Pages，不新建站点或部署平台。

## 标准开发流
`【计划】` → 更新 `PLAN.md` → `【开发】` → `【审查】` → `【测试】` → `【产品】` → `【修复】` → `【测试】` 回归。
