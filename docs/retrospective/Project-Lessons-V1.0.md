## 1. 最初目标与当前已核实状态

**目标**：个人网站 / 作品集——展示作品、提供成品与源码入口，并作为对外身份页（托管在 GitHub Pages 域名下）。

**已核实**：站上现有 37 个详情页，但**首页与卡片没有指向详情页的链接**（详情页成为孤儿页）；README 写 35 件、实际 37 件；双语与主题存在「三处维护」导致的派生数字漂移。

**证据缺口**：①原始 Day 1 对话不可得；②未运行构建与测试；③未做浏览器视觉验收；④外链未逐个实测。

## 3. 可预防返工 Top 5

1. **站上挂第三方代充/推广 → 全域名被 Safe Browsing 拉黑**（`1af6696`）：一次误加商业内容，代价是整个域名的可达性。预防：Day 1 明确「站上放什么、不放什么」，商业/代充类一律不进个人站。
2. **模板错配**：全栈模板用于纯展示站，后续两次构建迁移（`dbc1fcc` → `0a9ccd6` → `430b9cf`）。预防：先按站点类型（静态展示 / 需后端）选模板。
3. **作品全集未一次盘清**：8 → 14 → 23 → 27 → 32 → 37 多轮对账，README 与页面数字长期不一致。预防：Day 1 一次性给全作品清单，并让清单成为唯一真源。
4. **卡片语义三次纠正 + 详情页成孤儿**：卡片只该有「成品 + 源码」两个出口，纠正过程中把 37 个详情页做成无入口页。预防：先定「点卡片去哪」，再实现。
5. **外链无发布前巡检**：仓库改名、私有仓、平台下线、封面热链都曾导致死链。预防：发布前跑一次外链巡检。

## 4. 正常迭代

- 视觉方向探索与素材校准。
- 作品数量持续增长（不是返工，只是内容增长）。
- 双语与主题后置。
- 托管平台迁移（属平台条件变化）。

## 5. 计划者原本应前置发现

1. 内容红线与合规（不得放商业推广/代充）。
2. 模板的多余能力（全栈模板对纯展示站是负担）。
3. 作品全集与计数真源。
4. 卡片出口语义（成品 / 源码 / 详情）。
5. 部署主备地址与验收通道。
6. 外链健康检查。
7. 详情页定位：要么有入口，要么明确标注「存档页」。
8. 派生数字（作品数、阶段数）自动化，避免手写漂移。

## 6. UI / 信息架构可复用经验

| 规则 | 适用条件 | 边界 |
|---|---|---|
| 卡片只放「成品 + 源码」两个出口 | 作品集 | 有详情页时必须另有入口，否则成孤儿 |
| 密度用真实尺寸量，不靠目测 | 手机端 | 桌面可双栏 |
| 筛选计数钉右侧、标签自行换行 | 分类筛选 | 标签过多时改下拉 |
| 主题/语言新增必须三处同步 | 多语言多主题 | 漏一处即出现数字漂移 |
| 手机页头不要同时塞导航与两个开关 | 小屏 | 低频入口收进菜单 |

## 7. 外部条件与验证经验

- **开工硬阻塞**：内容边界与合规、作品清单、素材比例与版权、主备地址与验收通道。
- **开发者自办**：构建与部署流水线、外链巡检脚本、派生数字自动生成、真实点击测试。
- **验收**：必须在浏览器里真实点击（首页 → 卡片 → 详情 → 外链），不能只看代码；外链全量实测。

## 8. 下次同类项目应在 Day 1 确认的内容

1. 站上放什么、绝对不放什么。
2. 作品清单一次给全（数量与分类）。
3. 点卡片去哪（成品 / 源码 / 详情）。
4. 主备地址与验收通道。
5. 要不要英文、几套主题。
6. 素材比例与版权来源。
7. 是否需要搜索、筛选与详情页。
8. 谁签收视觉与内容。

## 9. 适用范围、反例与不能推广

- **适用**：个人展示 / 作品集静态站。
- **反例 1**：作品为零者可渐进补内容，不必一次盘清。
- **反例 2**：单页工具站不需要筛选与详情页体系。
- **反例 3**：内部非公开站不适用搜索风控规则。
- **不能推广**：「所有作品都要有详情页」不成立——没有内容支撑的详情页只会成孤儿。

## 10. 责任划分与下一次做法

| 责任方 | 表现 | 下次做法 |
|---|---|---|
| 用户 | 内容边界、受众、参考风格、素材 | Day 1 明确「不许放什么」，并给全作品清单 |
| 顾问/计划者 | 模板匹配、合规、外链、部署与验证通道 | 开工先判断「这个站该用什么模板」，别默认全栈 |
| 开发者 | 实现、量测、真实点击与外链测试、派生数字自动化 | 不擅自加商业化内容；列表数字自动生成 |

**一句话结论**：本项目最贵的一次事故是**内容合规**（第三方代充导致整个域名被 Safe Browsing 拉黑），其余返工集中在**模板错配、作品清单不完整、卡片出口语义未定**——都是 Day 1 说清就能避免的；视觉与素材迭代属正常演化。
