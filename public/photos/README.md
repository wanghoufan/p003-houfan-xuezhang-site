# 网站照片文件夹

网站实际读取以下轻量 WebP 文件：

- `profile.webp`：个人照片，建议竖版 4:5
- `coffee.webp`：咖啡
- `reading.webp`：阅读
- `guitar.webp`：吉他
- `fitness.webp`：健身
- `basketball.webp`：篮球
- `dance.webp`：抖舞
- `snowboard.webp`：滑雪
- `surf.webp`：冲浪

JPG、PNG 高清原图保存在项目的 `assets/photo-originals/` 文件夹，不参与网站发布。以后更换照片时，应先从原图生成对应的 WebP 文件，再重新发布网站。
